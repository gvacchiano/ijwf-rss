# IJWF RSS feed

Clean RSS 2.0 feed for **International Journal of Wildland Fire**, intended for Feedly.

- Feed file: `docs/ijwf.xml`
- Generator: `generate_feed.py`
- Metadata source for automatic updates: Crossref, eISSN `1448-5516`
- Journal: https://connectsci.au/wf

The initial feed contains the latest IJWF articles available from the publisher feed as of 14 August 2026.

Once GitHub Actions is enabled, the generator can refresh `docs/ijwf.xml` automatically every day.
